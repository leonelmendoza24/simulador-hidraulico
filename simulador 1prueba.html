Fundamento matemático del modelo

A. Flujo uniforme: ecuación de Manning y números decimales
Q = (1/n) · A · R2/3 · S01/2, A = b·y, P = b + 2y, R = A/P

El tirante normal yn no tiene solución algebraica cerrada. Se obtiene por bisección sobre Q(y), que es monótona creciente. El número de Froude Fr = V / √(g·y) clasifica el régimen. El tirante crítico de una sección rectangular es yc = (Q² / (g·b²))1/3. Todos los cálculos se hacen en doble precisión y solo se redondean con toFixed() al mostrarlos, de modo que no se acumula error de redondeo.

B. Ecuaciones lineales: costo de mitigación y pérdida de carga
Costo(V) = Vesc · Tarifam³ + Cargofijo, Tarifam³ = ebombeo · TarifakWh

Vesc = Qexc · t es el volumen que el canal no puede conducir durante el pico. Se tomó el cargo fijo como un costo de movilización que se activa solo cuando hay excedente (Vesc > 0).

hf,lin = (32 · ν · L / (g · Dh²)) · V, Dh = 4R

Es la relación lineal en V de Hagen-Poiseuille, válida para régimen laminar. En un arroyo urbano el flujo casi siempre es turbulento (Re muy alto), por eso el simulador la muestra junto a la pérdida por Manning, hf = (n·V / R2/3)² · L, y advierte que la aproximación lineal solo sirve como referencia.

C. Ecuaciones cuadráticas: geometría óptima y trayectoria del chorro

Con el perímetro de revestimiento fijo Pm = b + 2H (material disponible), el área en función del ancho x es una parábola:

A(x) = x · (Pm − x) / 2 = −x²/2 + (Pm/2) · x

Su vértice da la sección de máxima área: x* = Pm/2, H* = Pm/4 y Amáx = Pm²/8, es decir b = 2H (sección rectangular de máxima eficiencia hidráulica). Para un área dada A, los anchos posibles salen de x² − Pmx + 2A = 0, con discriminante Pm² − 8A ≥ 0.

y(x) = h0 + tan(θ)·x − g / (2·v0²·cos²θ) · x²

Con v0 = Q / Asalida. El alcance es la raíz positiva de y(x) = 0: xL = [tanθ + √(tan²θ + 4·a·h0)] / (2a), con a = g / (2·v0²·cos²θ).

D. Compuerta y supuestos del modelo
Q = Cd · b · hg · √(2·g·y1), Cd = 0.60
  • Canal prismático rectangular, flujo permanente y uniforme en el tramo (la compuerta se trata como control aguas abajo).
  • Si la compuerta controla, el tirante aguas arriba y1 se despeja de la ecuación de descarga. El remanso se dibuja con un perfil suave de referencia, no con una integración de flujo gradualmente variado.
  • Hay desborde cuando el tirante efectivo supera la altura de los muros H, o de forma equivalente cuando Qin supera la capacidad.
  • La velocidad de salida del chorro usa Asalida = b · min(hg, y). No se aplica coeficiente de contracción.
  • Es una herramienta didáctica. No sustituye un modelo 1D/2D calibrado (HEC-RAS, SWMM, IBER) para diseño.
